# Dr. Kristina Tykhonova — сайт косметолога

Багатосторінковий статичний сайт (HTML/CSS/JS, без залежностей у продакшені).
Дизайн-стиль: **Deep Ocean** — глибокий синій + біло-сірий + темно-бірюзові акценти.

## Структура

```
index.html            Головна
about.html             Про мене
services.html          Хаб послуг (усі 16, згруповані)
services/<slug>.html   16 окремих сторінок послуг
certificates.html      Сертифікати / навчання
gallery.html            Галерея До/Після
reviews.html            Відгуки клієнтів
price.html               Прайс
contacts.html             Контакти

css/style.css            Усі стилі сайту (Deep Ocean design system)
js/main.js                Меню, FAQ, лайтбокс, анімації появи
images/                    Фото (логотип + реальні фото)

build/                     Генератор сторінок (Node.js, без npm-залежностей)
  data/site.js              Бренд, контакти, локації, навігація
  data/services.js          Контент усіх 16 послуг
  data/gallery.js            Фото "До/Після"
  data/certificates.js        Фото навчань/сертифікатів
  data/prices.js               Ціни (порожньо — додавайте самі)
  data/reviews.js               Відгуки (порожньо — додавайте самі)
  templates.js                 Компоненти (шапка/підвал/кнопки/картки)
  generate.js                    Збирає всі *.html з даних вище
```

## Як що-небудь змінити

Сайт — це **готові HTML-файли**, їх можна редагувати вручну. Але якщо
потрібно змінити щось на всіх сторінках одразу (телефон, послугу,
додати ціну) — зручніше відредагувати дані в `build/data/*.js` і
перегенерувати сайт:

```
node build/generate.js
```

Це перезапише всі `*.html` файли на основі даних. Потрібен лише
Node.js (npm-пакети не використовуються).

### Додати ціну в прайс
Відкрийте `build/data/prices.js`, впишіть рядок на кшталт:
```js
'lip-contouring': 'від 3 000 грн',
```
(slug зі списку в `services.js`) і запустіть генератор.

### Додати відгук
Відкрийте `build/data/reviews.js` і додайте об'єкт `{ name, service, text, date }`
у масив, потім запустіть генератор.

### Додати нову послугу
Скопіюйте один об'єкт у `build/data/services.js`, змініть поля,
запустіть генератор — нова сторінка `/services/<slug>.html` створиться
автоматично разом із карткою в меню, на головній та в хабі послуг.

### Змінити контакти/телефон/соцмережі
Усе це в `build/data/site.js`.

## Публікація

Просто завантажте вміст цієй папки (крім `build/`, він не потрібен
у продакшені, але не заважає) на будь-який статичний хостинг —
файли самодостатні, збірка не потрібна.

## Примітки щодо контенту

- **Відгуки** поки не додано навмисно — на сайті не повинно бути
  вигаданих відгуків. Порожній стан на `reviews.html` веде на
  Instagram/Telegram, поки не з'являться реальні тексти.
- **Прайс** має структуру, готову до заповнення (див. вище), але
  конкретні ціни навмисно не вигадані.
- **Сертифікати** — наразі показані фото з профільних заходів
  (конференція May Aesthetics Meeting тощо). Скани самих сертифікатів
  можна додати в `build/data/certificates.js`, коли вони будуть готові.
